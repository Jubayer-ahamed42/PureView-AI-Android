# 🛡️ PureView AI — ১০০% অ্যান্ড্রয়েড ইসলামিক এআই অ্যাপ (বাংলা গাইড)

**PureView AI** হলো শুধুমাত্র **অ্যান্ড্রয়েড মোবাইল ইউজারদের জন্য (100% Android-Focused)** তৈরি একটি ফ্ল্যাগশিপ ইসলামিক এআই অ্যাপ। মোবাইলে **YouTube** এবং **Facebook** চালানোর সময় যেকোনো মেয়ের চেহারা (**Female Face**—সাধারণ পোশাক, শাড়ি বা হিজাব যা-ই পরে থাকুক না কেন) ও অশালীন ছবি **১০০% রিয়েল-টাইমে ব্লার (Blur)** করে আপনার চোখের হেফাজত নিশ্চিত করে।

---

## ✨ মূল ফিচারসমূহ (Key Features)

1. **⚡ Zero-Leak Blur-First Technology (০ সেকেন্ডে চোখের সুরক্ষা):**
   - মোবাইলের ইউটিউব বা ফেসবুক ফিডে যেকোনো ছবি (`<img>`, `background-image`), থাম্বনেইল, রিলস (Reels) বা শর্টস (Shorts) লোড হওয়ার **সাথে সাথেই (০ মিলিসেকেন্ডে)** CSS দিয়ে ডিফল্টভাবে ব্লার (`filter: blur(25px)`) হয়ে থাকে—যাতে ১ মিলিসেকেন্ডের জন্যও মেয়ের ছবি চোখে না পড়ে!
2. **🧠 Real Female-Face & Gender Classification AI (`@vladmandic/face-api` + WASM Neural Engine):**
   - সরাসরি ছবির ভেতরে থাকা মানুষের **চেহারা (Face)** এবং **লিঙ্গ (Gender: Female vs Male)** শনাক্ত করে।
   - **মেয়ের চেহারা (Female Face)** পাওয়া গেলে ছবিটির ওপর **স্থায়ী গাঢ় ব্লার (Permanent Heavy Blur)** লক করে রাখে।
   - আর **পুরুষের ছবি (Male Scholar/Speaker)**, **প্রাকৃতিক দৃশ্য (Mosque/Nature)** বা **টেকনোলজির ছবি** হলে সাথে সাথে ব্লার সরিয়ে ছবিটি **১০০% পরিষ্কার (Clear)** করে দেয়!
3. **🔓 CORS Bypass Proxy & Android WebView Interceptor:**
   - ইউটিউবের ইমেজ সার্ভার (`i.ytimg.com`, `yt3.ggpht.com`) এবং ফেসবুকের ইমেজ সার্ভার (`scontent.*.fbcdn.net`) যেন কখনোই `CORS` এরর দিয়ে AI স্ক্যানিং ব্লক করতে না পারে, সেজন্য লোকাল প্রক্সি (`/api/proxy-image`) এবং নেটিভ অ্যান্ড্রয়েড ওয়েবভিউ ইন্টারসেপ্টর (`PureViewWebViewClient.java`) যুক্ত করা হয়েছে।
4. **📲 ৩টি প্রিমিয়াম মোবাইল ট্যাব (Touch-First Emerald Islamic UI):**
   - **▶️ ট্যাব ১ — Halal YouTube:** অটোমেটিক ফিমেল থাম্বনেইল ও শর্টস ব্লার + **Built-in YouTube Ad-Blocker** + **Background Audio Play** (স্ক্রিন বন্ধ রেখে কুরআন তেলাওয়াত, গজল ও ইসলামিক লেকচার শোনার সুবিধা)।
   - **📘 ট্যাব ২ — Halal Facebook:** নিউজফিড পোস্ট, স্টোরিজ (Stories), রিলস (Reels) এবং স্পন্সরড ফিমেল অ্যাড অটোমেটিক ব্লার।
   - **🛡️ ট্যাব ৩ — PureView Shield Settings:**
     - `PureView AI Shield: ON / OFF` মাস্টার সুইচ
     - `Blur Mode`: পুরো ছবি ব্লার (`Full Image Blur`) বনাম শুধুমাত্র মেয়ের চেহারার অংশটুকু ব্লার (`Face-Only Blur`)
     - `Blur Strength` স্লাইডার (`10px` হালকা থেকে `45px` আল্ট্রা গাঢ় ব্লার)
     - `Total Female Faces Blurred Today` লাইভ কাউন্টার এবং **🧪 Live Demo Test Feed**।

## 📱 পদ্ধতি ১: ওয়াইফাই (Wi-Fi) দিয়ে অ্যান্ড্রয়েড ফোনে সাথে সাথে ইনস্টল ও লাইভ টেস্ট (সবচেয়ে সহজ)

আপনার কম্পিউটার এবং অ্যান্ড্রয়েড ফোনটি একই Wi-Fi (অথবা মোবাইল হটস্পট)-এ কানেক্ট করে মাত্র ১ মিনিটে ফোনে অ্যাপটি চালাতে ও ইনস্টল করতে পারবেন:

### ধাপ ১: সার্ভার চালু করুন
প্রজেক্ট ফোল্ডারে (`C:\MY PROJECT\3. PUREVIEW AI`) টার্মিনাল বা PowerShell ওপেন করে নিচের কমান্ডটি দিন:
```bash
npm start
```
টার্মিনালে নিচের মতো দুটি লিংক দেখতে পাবেন:
- `📱 Local URL: http://localhost:3000`
- `📶 Android Wi-Fi: http://192.168.x.x:3000` *(অথবা আপনার Wi-Fi IP)*

### ধাপ ২: অ্যান্ড্রয়েড ফোনে ওপেন ও ইনস্টল করুন
1. আপনার অ্যান্ড্রয়েড ফোনের **Chrome Browser** ওপেন করুন।
2. অ্যাড্রেস বারে টার্মিনালে দেখানো **`Android Wi-Fi` লিংকটি** (যেমন: `http://10.13.108.16:3000` বা `http://192.168.x.x:3000`) টাইপ করে ঢুকুন।
3. Chrome-এর উপরের ডান কোণায় **⋮ (Three Dots মেনু)**-তে ট্যাপ করে **"Add to Home screen" / "Install app"** বাটনে চাপ দিন।
4. সাথে সাথে আপনার অ্যান্ড্রয়েড ফোনের হোম-স্ক্রিনে **🛡️ PureView AI** অ্যাপটি একটি পূর্ণাঙ্গ মোবাইল অ্যাপ হিসেবে ইনস্টল হয়ে যাবে!

## 📦 পদ্ধতি ২: সরাসরি Android APK তৈরি ও ইনস্টল (`build-apk.bat` / Android Studio)

প্রজেক্টের ভেতরে সম্পূর্ণ নেটিভ অ্যান্ড্রয়েড ওয়েবভিউ প্রজেক্ট (`android/` ফোল্ডার) এবং ওয়ান-ক্লিক বিল্ড স্ক্রিপ্ট দেওয়া আছে:

### ওয়ান-ক্লিক স্ক্রিপ্ট দিয়ে:
1. প্রজেক্ট ফোল্ডারে থাকা **`build-apk.bat`** ফাইলটিতে ডাবল-ক্লিক করুন (অথবা টার্মিনালে `npm run build:apk` চালান)।
2. এটি স্বয়ংক্রিয়ভাবে সব ওয়েব অ্যাসেট ও AI মডেলগুলো `android/app/src/main/assets/public/` ফোল্ডারে সিঙ্ক করবে এবং আপনার পিসিতে Android SDK ও JDK থাকলে সরাসরি **`PureView-AI-Android.apk`** তৈরি করে দেবে।

### Android Studio দিয়ে APK তৈরি করতে চাইলে:
1. **Android Studio** ওপেন করে **Open Existing Project**-এ যান এবং `C:\MY PROJECT\3. PUREVIEW AI\android` ফোল্ডারটি সিলেক্ট করুন।
2. উপরের মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)**-এ ক্লিক করুন।
3. তৈরি হওয়া `app-debug.apk` ফাইলটি আপনার অ্যান্ড্রয়েড ফোনে পাঠিয়ে ইনস্টল করে নিন!
